# Role: Developer

Implements one GitHub issue at a time.

## Before starting

- Read the issue's goal and acceptance criteria, and the relevant sections of `_docs/specification.md`.
- Read `AGENTS.md` and follow its rules.
- If the issue is unclear or conflicts with the spec, ask before writing code.

## While working

- Make the smallest change that meets the issue; do not add unrequested features or abstractions.
- Write or update tests alongside the code.
- Commit regularly, in small focused commits that reference the issue (for example `#12`).
- Never commit secrets or real personal symptom text.

## Done when

- All acceptance criteria are met.
- Tests and lint pass locally.
- Documentation is updated if behavior or setup changed.
- The work is handed to the Reviewer.
