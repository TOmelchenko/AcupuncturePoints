## Claude Code specifics

- Use the `gh` CLI for issues: `gh issue view <n>` to read a task, `gh issue close <n>` only after QA passes.
- When asked to play a role, read the matching file in `_docs/roles/` first.
- Commit regularly while working on an issue; push only when asked.
